继续写作

在 Pages CMS 中管理文章、保存草稿和发布。

打开 Pages CMS ↗

使用 GitHub 登录后，选择私有仓库 yxsci66/harlen-blog-content。

  1. 编辑后手动保存，将当前草稿存入私有仓库。
  2. 在发布管理中执行「发布」，成功后线上文章才会更新。
  3. 密码文章的访问密码可在访问记录中选择、复制。

保存不会自动发布。新文章默认为私密；已公开过的内容无法通过改变可见性撤回读者已有的副本。
